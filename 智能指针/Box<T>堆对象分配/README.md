# Box\<T\>堆对象分配

Box\<T\> 是Rust中用于堆分配的智能指针，它可以用来在堆上分配一个值并获取一个指向它的指针。Box\<T\> 的类型参数T表示被分配的值的类型


## 指针与智能指针

指针是**存储内存地址的变量**，它可以指向任意的内存地址，可以用来读取或修改存储在该地址中的数据。在Rust中，最主要的指针是引用 (reference)，在不获取所有权的情况下，也可以访问对象

而智能指针是**一种数据结构**，它的行为类似指针，但它有**元数据**和**附加的额外功能**。例如引用计数智能指针 `Rc<T>`，它会跟踪指向堆上数据的引用数量，当最后一个引用被销毁时，它会自动释放堆上的数据

通常智能指针使用结构体实现，并通过实现 `Deref` 和 `Drop` 两个trait来实现指针的行为

- `Deref` trait允许智能指针像引用一样访问其指向的数据
- `Drop` trait允许智能指针在离开作用域时释放其指向的数据

## Box\<T\>

Box\<T\>是Rust中用于堆分配的智能指针，它可以用来在堆上分配一个值并获取一个指向它的指针

- `T`：被分配的值的类型

```rust
let x = Box::new(5);
```

上述代码是将值 `5` 存储在堆上，并获取一个指向它的指针，存入在栈上的变量 `x` 中

## 应用示例——Cons

Cons 是一种常见的递归数据结构，它是一种链表，但它是通过递归定义的，每个节点包含一个值和一个指向下一个节点的指针

[Cons](https://en.wikipedia.org/wiki/Cons)

```rust
enum List {
    Cons(i32, List),
    Nil,
}
```

在非递归枚举中，Rust 知道具体要分配多少内存来存储枚举成员，因此不会报错

但是， `List` 是一个**递归类型**，Rust 不知道具体要分配多少内存来存储 `Cons` 节点，因此会报错

```
error[E0072]: recursive type `List` has infinite size
```

为解决这个问题，我们可以使用 `Box<T>` 来分配 `Cons` 节点，而 `Box<T>` 本身就是一个固定大小的智能指针，将数据存储其他位置 (堆区)，只有指针存储在枚举成员中，所以不会造成递归类型错误

```rust
enum List {
    Cons(i32, Box<List>),
    Nil,
}
```

```rust
fn main() {
    let list = List::Cons(1, Box::new(List::Cons(2, Box::new(List::Nil))));
}
```
